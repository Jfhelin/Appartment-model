# Interior visual references

The images are grouped by their primary subject. Filenames are short identifiers; this catalog records what each view appears to show and the approximate camera direction inferred from the frame. Camera positions and directions are not measured.

Treat these as visual references, not as a source of dimensions or definitive evidence that every furnishing, finish, fixture, or detail matches the apartment. Their provenance and consistency with one another have not been established. Use [`../floor-plan.jpg`](../floor-plan.jpg) for the labeled room layout and adjacency, and resolve conflicts against verified information.

## Using and extending this set

- Keep each image in the folder for its primary viewpoint; use this catalog to note when it also helps interpret an adjacent room.
- Add a short, descriptive filename and a catalog row that states the inferred camera position/direction, visible architectural cues, and any uncertainty.
- Use wide views to understand room relationships and openings, and close views only for visible detail. Neither type establishes metric dimensions.
- Keep reference images separate from model outputs and edited derivatives. Record any confirmed corrections or unresolved conflicts in project/model documentation.
